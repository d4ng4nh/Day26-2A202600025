# Link tải Báo cáo Phân tích Lab 2 (Slide Deck)

Vì Lab 2 yêu cầu sản phẩm cuối cùng là **Slide Deck định dạng PDF**, chúng tôi đã chuẩn bị sẵn nội dung phân tích xuất sắc ở định dạng Slide Markdown trong file `analysis-report.md`.

## Cách biến `analysis-report.md` thành file PDF nộp bài:

1. **Sử dụng Marp (Nhanh nhất)**:
   - Cài đặt extension **Marp for VS Code** trong trình biên tập của bạn.
   - Mở file `analysis-report.md`, nhấn chuột phải và chọn `Marp: Export Slide Deck`.
   - Lưu dưới tên `analysis-report.pdf` vào đúng thư mục này.

2. **Dùng Google Slides / Canva (Thủ công)**:
   - Bạn có thể tạo một file Google Slides mới.
   - Copy từng phần nội dung từ `analysis-report.md` dán vào các slide tương ứng.
   - Chèn các ảnh chụp màn hình từ thư mục `screenshots/` vào slide.
   - Tải xuống dưới dạng PDF (`File > Download > PDF Document`).
